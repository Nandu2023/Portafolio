01Este documento describe tres alternativas para implementar y utilizar un servidor MCP orientado a la interacción con un cliente SAP mediante herramientas asistidas por inteligencia artificial. Cada usuario puede seleccionar la opción que mejor se ajuste a su entorno técnico, licenciamiento disponible y preferencia de trabajo.

Las alternativas incluidas son

04Implementación con Antigravity usando Claude o Gemini.

Guía paso a paso

Consideraciones de seguridad

No compartir archivos .env, capturas de pantalla con credenciales, tokens, URLs internas sensibles o configuraciones privadas.

Verificar que el archivo .gitignore incluya .env y cualquier archivo local con información confidencial antes de hacer commits o publicar cambios.

Usar valores genéricos en ejemplos documentales, como <usuario>, <contraseña>, <cliente> y <url_sap>.

Si el cliente SAP requiere VPN, conectarse antes de ejecutar pruebas de acceso. Si la herramienta solicita autenticación inicial sin VPN, seguir la recomendación específica indicada en cada sección.

01Conceder permisos de ejecución únicamente cuando se comprenda la acción solicitada por la herramienta.
